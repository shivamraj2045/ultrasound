# **App Name**: MediScan Clinic

## Core Features:

- Dashboard Overview: Provides a summarized view of clinic stats including total patients, scans, remaining credits, and subscription status.
- Patient Management: Allows creation and management of patient records including name, age, gender, and scan history.
- Ultrasound Scan Workflow: Step-by-step process for conducting ultrasound scans, including patient selection, body part selection, credit deduction, and scan saving.
- Scan History: Comprehensive history of all scans performed, including patient details, body part scanned, date, credits used, and scan status.
- Alerting System: Displays medical alerts for abnormal detections, system alerts for device status, and business alerts for low credits and subscription expiry.
- Credit Management: Manages credit balance and allows purchase of additional credits.
- Personalized Report Generation: Using AI, the app intelligently analyzes the context of each scan (patient history, selected body part) to produce short descriptions about how likely various pathologies are, with clear qualifiers, acting as a 'tool' for the medical professional's decision.

## Style Guidelines:

- Primary color: Deep sky blue (#42A5F5) for a professional and trustworthy feel.
- Background color: Light blue (#E1F5FE) to create a calm and clean environment.
- Accent color: Light steel blue (#B0BEC5) for interactive elements and highlights.
- Body and headline font: 'Inter', a sans-serif font known for its modern and objective look, ensuring readability and a clean aesthetic. Use 'Source Code Pro' for computer code.
- Use a set of modern and consistent icons, focused on clarity. Color them a desaturated steel blue to complement the chosen primary color.
- Clean and structured layout with clear visual hierarchy for easy navigation. Use Tailwind CSS grid and flexbox for responsive design.
- Subtle animations and transitions for a smooth user experience, avoiding any distracting or unnecessary effects.
